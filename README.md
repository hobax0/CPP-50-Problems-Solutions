# 50 C++ Problem-Solving Solutions 🚀

A comprehensive C++ repository containing clean, structured, and modular solutions for 50 fundamental programming and algorithmic challenges.

---

## 📌 Project Overview
This repository showcases practical solutions to 50 logic-building and problem-solving exercises in **C++**. Each problem is implemented with standard practices using modular functions, structures, enumerated types, and clean control flow structures.

---

## 📂 Topics & Concepts Covered

The solutions cover a broad spectrum of core programming and algorithmic concepts:

| Category | Key Concepts Covered |
| :--- | :--- |
| **Control Flow & Logic** | Conditional Statements (`if-else`, `switch`), Loop Structures (`for`, `while`, `do-while`), Logic Validation |
| **Modular Programming** | Function Declarations, Parameter Passing, Pass-by-Reference (`&`), Reusable Utility Functions |
| **Data Structures & Types** | Custom `struct` Definitions, `enum` for Types/States, Built-in Primitive Types |
| **Math & Algorithms** | Mathematical Calculations, Geometric Formulas, Factorials, Power Functions, Prime Number Checking |
| **System Mechanics** | ATM PIN Verification Logic, Tax/Commission Calculations, Duration & Unit Conversions |

---

## 🛠️ Tech Stack & Requirements

* **Language:** C++ (C++11 or higher recommended)
* **IDE / Compiler:** Visual Studio / GCC / Clang
* **File Structure:**
  * `Solving Problems 1 to 50.cpp` — Main source code file containing all 50 solutions and interactive `main()` tests.

---

## 🚀 How to Run

### Option 1: Visual Studio (Recommended)
1. Clone or download this repository.
2. Open `Solving Problems 1 to 50.slnx` or `Solving Problems 1 to 50.vcxproj` in Visual Studio.
3. Uncomment the specific problem call in `main()` that you wish to run.
4. Build and run (`Ctrl + F5`).

### Option 2: Command Line (GCC/G++)
```bash
# Clone the repository
git clone https://github.com/hobax0/Cplusplus-50-Problems.git

# Navigate to project directory
cd Cplusplus-50-Problems

# Compile the source code
g++ -o main "Solving Problems 1 to 50.cpp"

# Run the executable
./main
```
